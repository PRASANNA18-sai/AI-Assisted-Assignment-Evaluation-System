# EduSubmit AI – AI-Assisted Assignment Evaluation System

## 📌 Project Overview

EduSubmit AI is an AI-powered academic submission and evaluation platform designed to simplify assignment management for students and educators. The system provides a centralized environment where students can submit assignments, track submission status, and receive evaluation feedback, while faculty can efficiently review, assess, and manage academic work.

The platform aims to reduce manual effort, improve transparency in the evaluation process, and enhance the overall learning experience through intelligent automation and analytics.

---

## 🚀 Features

* Student Assignment Submission
* Faculty Evaluation Dashboard
* AI-Assisted Feedback Generation
* Submission Status Tracking
* Performance Analytics
* Role-Based Authentication
* Secure Data Management
* Responsive User Interface
* Real-Time Updates
* Modern React-Based Architecture

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/PRASANNA18-sai/AI-Assisted-Assignment-Evaluation-System.git
```

Move into the project folder:

```bash
cd AI-Assisted-Assignment-Evaluation-System
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 📖 Abstract

EduSubmit AI is an intelligent academic submission and evaluation platform developed to streamline the process of managing assignments, projects, and assessments. The system allows students to upload academic work digitally while enabling faculty members to review, evaluate, and manage submissions efficiently. AI-assisted capabilities help improve feedback generation, submission tracking, and academic performance analysis. The platform offers role-based access control, secure data handling, deadline monitoring, and analytical insights that support effective decision-making. By automating routine academic workflows and providing intelligent assistance, EduSubmit AI enhances transparency, reduces manual workload, and improves the educational experience for both students and educators.
